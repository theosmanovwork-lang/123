# Prufbase — дизайн-система (для переноса в мобильное приложение)

Источник: лендинг Prufbase (`src/app/globals.css`, `src/components/sites/prufbase/*`). Все значения сняты с кода и проверены на живой странице. Машиночитаемая версия токенов: `tokens.json` рядом.
Единицы: 1 px веба = 1 dp (Android) = 1 pt (iOS).

## 0. Суть и характер
**Prufbase** — витрина верифицированной выручки российских инди-фаундеров: «Пруф вместо скриншота». Визуальный язык: тёмный, плотный, «терминальный» по плотности данных, спокойный, без декора. Эстетика заимствована у linear.app: холодные нейтральные поверхности, тонкие полупрозрачные линии, Inter, мягкие размытия при появлении.

Принципы:
1. **Данные первыми.** Числа (MRR, ARR, рост) — самый заметный элемент после заголовка; всегда моноширинные, с табличными цифрами.
2. **Один акцент — нейтральный.** Нет цветного бренда: акцент это почти белый на тёмном и графит на светлом. Цвет не несёт смысла «хорошо/плохо» (рост не зелёный, падение не красное: падение лишь приглушённое).
3. **Плоский интерфейс.** Нет теней. Иерархия строится поверхностями (`background` → `surface` → `surfaceMuted`) и 1-px линиями.
4. **Тёмная тема — дом, светлая — гостевая.** Приложение стартует в тёмной (или следует системе).
5. **Доверие важнее красоты.** Мелкий текст не меньше 11, контраст не ниже AA, цели нажатия не меньше 44.

## 1. Цвета
Токены по ролям. Тёмная тема — основная.

| Роль | Тёмная | Светлая | Где используется |
|---|---|---|---|
| `background` | `#08090A` | `#FFFFFF` | фон экрана |
| `surface` | `#0F1011` | `#F9F8F9` | карточки, панели, блоки |
| `surfaceMuted` | `#141516` | `#F4F2F4` | аватары-плитки, поля, вложенные блоки |
| `hover` / pressed row | `#FFFFFF0D` | `#EEEDEF` | нажатие/hover строки, ghost-кнопки |
| `border` | `#FFFFFF14` (белый 8%) | `#E4E2E4` | все линии и рамки карточек |
| `fieldBorder` | `#62666D` | `#7B808A` | рамка поля ввода (контраст ≥3:1) |
| `textPrimary` | `#F7F8F8` | `#1C1D1F` | заголовки, основной текст |
| `textSecondary` | `#D0D6E0` | `#3A3C41` | лиды, описания секций |
| `textMuted` | `#9CA1AB` | `#4A4E56` | подписи, мета, плейсхолдеры |
| `accent` | `#E5E5E6` | `#1C1D1F` | галочка «подтверждено», теги, линии графиков |
| `onAccent` | `#08090A` | `#FFFFFF` | текст на `accent` |
| `accentText` | `#D0D6E0` | `#1C1D1F` | акцентные подписи («01», eyebrow, слэш в логотипе) |
| `ctaFill` / pressed | `#E5E5E6` / `#FFFFFF` | `#1C1D1F` / `#3A3C41` | главная кнопка (светлая «таблетка» на тёмном) |
| `focusRing` | `#8A8F98` | `#62666D` | фокус (3 px, 30–50% прозрачности) |

Контрасты (измерены): `textPrimary` на `surface` 17.9:1, `textSecondary` 13:1, `textMuted` 7.0–7.7:1 (AAA), рамка поля ≥3:1. Выделение текста: `textPrimary` 22% поверх фона.
Правила: полупрозрачные границы поверх любой поверхности; не вводить зелёный/красный в метрики роста; красный (`destructive`) только для ошибок/деструктивных действий.

## 2. Типографика
**Шрифты.** Inter Variable (лицензия OFL; файл тот же, что у Linear) c OpenType-фичами `cv01`, `ss03`; JetBrains Mono (OFL) для чисел, подписей и кода. Берклей-моно и Tiempos не используются (платные).
- Android: `fontFeatureSettings = "cv01, ss03"`; iOS: через `UIFontDescriptor` features/`.fontDesign`; React Native/Flutter: `fontFeatures`.
- Веса: 400 (текст), **510** (заголовки и «semibold/medium»), **590** (жирный: названия, значения), оптическое различие между 510 и 590 небольшое — не подменять на 600/700.

**Шкала** (десктоп → мобайл; для приложения берите колонку «Мобайл»):

| Стиль | Мобайл | Десктоп | Вес | Трекинг | Цвет |
|---|---|---|---|---|---|
| Display (H1) | 36/39 | 64/67 | 510 | −2.2% | textPrimary |
| H2 секции | 30/36 | 48/53 | 510 | −2.2% | textPrimary |
| H3 карточки | 18/28 | 18/28 | 590 | 0 | textPrimary |
| Lead | 16/26 | 18/29 | 400 | 0 | textSecondary |
| Body | 15/24 | 15/24 | 400 | 0 | textSecondary |
| Body small | 14/20 | 14/20 | 400 | 0 | textMuted |
| Title (имя в списке) | 14/18 | 14/18 | 590 | 0 | textPrimary |
| Caption | 12/16 | 12/16 | 400 | 0 | textMuted |
| Label | 11/15 | 11/15 | 590 | +2% | textMuted |
| Label caps | 11/15 | 11/15 | 590 | +5%, UPPERCASE | textMuted |
| Eyebrow (mono) | 12/16 | 12/16 | 400 | +5%, UPPERCASE | accentText |
| Figure XL (mono) | 20/28 | 24/32 | 590 | 0 | textPrimary |
| Figure (mono) | 14/20 | 14/20 | 590 | 0 | textPrimary |
| Figure S (mono) | 11/15 | 11/15 | 590 | 0 | textPrimary |

Правила: все числа и суммы — mono + табличные цифры (`tabular-nums`), валюта через неразрывный пробел (`412 300 ₽`), компактно: `412 тыс. ₽`, `2,4 млн ₽`; десятичный разделитель — запятая (`1,0x`). Минимум 11 pt для любого текста; заглавными (caps) только короткие метки. Заголовки: балансировка переносов (`text-wrap: balance` → в приложении ручная расстановка/`lineBreakStrategy`).

## 3. Сетка, отступы, формы
- Сетка 4. Поля экрана 16. Шаги: 4, 8, 12, 16, 20, 24, 32, 48, 64, 96.
- Расстояние между секциями: 64 (мобайл), 96 (десктоп). Внутри карточек 12–20.
- Радиусы: **8** (кнопки малые, поля, чипы), **10** (карточки, плитки аватаров), **14** (крупные панели), **pill** (CTA, теги, аватары-круги).
- Рамки 1 px `border`. Теней нет; только CTA имеет микротень в 5 слоёв (1–8 px, ≤8% чёрного).
- Размеры: аватар проекта 32 (r8), аватар фаундера 24 (круг), иконки 16, галочка в бейдже 14.
- Цели нажатия: минимум 44; основная кнопка 48 на всю ширину, поле ввода 44.

## 4. Движение
| Что | Параметры |
|---|---|
| Любой UI-переход (цвет, рамка, фон) | 160 мс, cubic-bezier(.25,.46,.45,.94) |
| Нажатие | масштаб 0.98 |
| Появление заголовка | по словам: opacity 0→1, blur 10→0, сдвиг вверх 20%→0; 700 мс, cubic-bezier(.25,.1,.25,1), задержка 80 мс + 25 мс на слово |
| Появление секций при скролле | opacity 0→1, blur 6→0, сдвиг 16→0, привязано к прокрутке (вход в экран 0–55%) |
| Липкая панель | выезд сверху 300 мс ease-out |
| Раскрытие FAQ | шеврон поворот 180° |
Reduced motion: убрать blur и сдвиг, оставить мгновенный opacity. На мобильных для экономии батареи blur только для заголовка онбординга.

## 5. Компоненты
Для каждого: структура, размеры, состояния.

**Wordmark.** Текст `Prufbase` (510, tracking −2%) + слэш `/` цветом `accentText`. Без иконки (бренд-правило: никаких щитов/галочек у логотипа).

**CTA-кнопка (primary).** Таблетка, высота 44 (48 при ширине на весь экран), горизонтальные отступы 20, текст 14/590, `ctaFill` + `ctaText`, иконка-стрелка 16. Нажатие: `ctaFillPressed` + scale .98. Disabled: 70% прозрачности. Малая версия (в липкой панели): высота 36, отступ 16.

**Поле ввода.** Высота 44, радиус 8, рамка 1 `fieldBorder`, фон `surfaceMuted` 60%, текст 16 (мобайл) / 14 (десктоп), плейсхолдер `textMuted`. Фокус: рамка `focusRing` + кольцо 3 px 30%. Сообщение об ошибке под полем 14 `accentText`. Под формой всегда мелкое пояснение 12 `textMuted` (согласие, «сейчас нужен только email»).

**Бейдж «Подтверждено».** Круг 14 `accent` + галочка 10 (stroke 3.5, цвет `onAccent`), текст 11/590 `accentText`: `Подтверждено · ЮKassa`. В карточке — только «Подтверждено», провайдер в мете.

**Тег «ПРОДАЁТСЯ».** 11/700 caps, фон `accent`, текст `onAccent`. В карточке: прижат в правый верхний угол, скругление только левого нижнего (8), отступ 8×2. В строке списка: pill, отступ 6×2.

**Плашка «Демо-данные».** Pill, рамка 1 `border`, mono 11 caps, `textMuted`, отступ 8×2. Ставится на любом блоке с примерными данными.

**Карточка проекта (лента).** Ширина 252, отступ 12, радиус 10, рамка 1, фон `surface`. Сверху: аватар 32 (буква проекта, плитка `surfaceMuted`, рамка) + название 14/590 (в одну строку) + мета 11 `textMuted` «Категория · Провайдер». Средняя строка: бейдж «Подтверждено» слева, спарклайн 72×24 справа. Нижняя строка — сетка 3 колонки с зазором 8: подпись 11 caps + значение mono 11/590 (`MRR | Рост | ARR` или `MRR | Цена | Мультипл.` для «Продаётся»). Нажатие: рамка светлеет до `accent` 50%. Лента — горизонтальный скролл, зазор 12, привязка к карточке, поля 16.

**Строка каталога.** Высота ~53. Колонки: ранг (mono 14 `textMuted`), проект (аватар 32 + название 14/510 + описание 12 `textMuted`, обрезка), фаундер (аватар-круг 24 + имя 14), источник (бейдж + провайдер), MRR (mono 14/590, справа), спарклайн 88×24, рост (`▲ 14%` / `▼ 2%`, mono). Между строками линия 1. Нажатие: фон `hover`. На узком экране остаются: ранг, проект (название+описание), MRR, рост.

**Спарклайн.** 12 точек (месяцы), линия 1.5 со скруглёнными концами, цвет `accentText`, без осей/подписей; в профиле — крупный (высота 112) с заливкой 12% и подписями месяцев mono 11 `textMuted`.

**Профиль проекта.** Заголовок: название 18/590 + бейдж + (демо-плашка). Два показателя в сетке 2×1: подпись 11 caps + значение mono 24/590 (`MRR`, `ARR`). Ниже график 12 месяцев. Блок «Код для встраивания»: mono 12 в рамке радиус 10 на `background`.

**Карточка шага / преимущества.** Радиус 14 (шаг) или 10 (фича), отступ 20/16, рамка 1, фон `surface`. Номер `01` mono 14 `accentText`, заголовок 18/590 (шаг) или 14/590 (фича), текст 14 `textMuted`. У фичи справа чип стадии: pill, mono 11 caps; «Первый релиз» — рамка `accent` 50% + текст `accentText`, прочие — рамка `border` + `textMuted`.

**Сравнение «Скриншот / Prufbase».** Две карточки (радиус 14); вторая подсвечена рамкой `accent` 40%. Внутри вложенный блок на `background`: у «Скриншота» пунктир и зачёркнутая цифра, у Prufbase — бейдж и цифра mono 30/590.

**Список безопасности.** Контейнер радиус 14 с разделителями 1 px; строка: заголовок 14/590 + текст 14 `textMuted`, отступ 16–20. Слева «код-карточка» с рамкой `accent` 40%: `GET` подсвечены `accentText`, `POST` приглушены и зачёркнуты.

**FAQ (аккордеон).** Контейнер радиус 14, рамка, разделители. Вопрос 14–16/590, высота строки ≥48, справа шеврон 16. Ответ 14 `textMuted`, нижний отступ 16.

**Чипы провайдеров.** Радиус 8, отступ 16×8, 14. «Стартуем с» — рамка `accent` 50% и вес 510; «Затем/Позже» — рамка `border`, цвет `textMuted`. Примечание (12) под названием. Заголовки групп — mono 12 caps `textMuted`.

**Липкая панель CTA.** Высота 56, фон `background` 80% + размытие 20, нижняя линия 1. Слева wordmark 16, справа малая CTA. Показывается, когда основная форма вышла из кадра; скрывается, когда видна нижняя форма (в приложении — при уходе кнопки CTA с экрана).

**Подвал.** Wordmark 18 + описание 14 `textMuted`, колонки ссылок 14 (высота строки ≥32), нижняя строка копирайта и переключатель темы (ghost-кнопка: иконка 16 + подпись).

**Слот спонсора.** Рамка пунктиром 1 `border`, непрозрачность 60%, mono 11 caps «Спонсорское место» + ссылка 12 «Узнать условия». На мобильном не показывается.

## 6. Шаблоны страниц (порядок блоков)
Лендинг сверху вниз: 1) Hero (wordmark → позиционирование → H1 → lead → форма → строка доверия → ссылки-якоря) → 2) две ленты карточек («Недавно подтверждены», «Продаются») → 3) «Проблема» (сравнение) → 4) «Как работает» (3 шага) + «Что ещё будет внутри» (6 фич) → 5) Каталог (таблица + профиль проекта) → 6) Безопасность → 7) Для кого (4 карточки) → 8) Провайдеры → 9) FAQ → 10) Финальный CTA → 11) Подвал. Липкая панель CTA поверх.
Заголовок секции — по центру: eyebrow (mono, caps) → H2 → лид (максимум 560 по ширине).

## 7. Предложение: как это перенести в приложение (мои рекомендации, не часть сайта)
Экраны: **Каталог** (список строк + фильтр «Продаётся»), **Профиль проекта** (MRR/ARR, график 12 мес., бейдж, код/поделиться), **Подключение провайдера** (шаги и объяснение «ключ только читает», как на лендинге), **Моё** (мои проекты, статус синхронизации), **Уведомления** (Telegram-бот уже в планах), **Настройки** (тема: система/тёмная/светлая).
Навигация: нижняя панель на 4 пункта, высота 56 + safe area, иконки 24, активный пункт `textPrimary`, остальные `textMuted`; без цветных бейджей.
Что адаптировать: горизонтальные ленты карточек оставить; таблицу каталога заменить списком строк (ранг, проект, MRR, рост; график по нажатию); липкую панель заменить закреплённой кнопкой внизу формы; размытие при появлении оставить только для онбординга.
Доступность: тексты ≥11, динамический шрифт, контраст не ниже AA, цели ≥44, `reduceMotion`.

## 8. Голос и тексты
Прямо, по делу, чуть дерзко, без рекламного языка («как в индихакерских постах, не как в рекламе банка»). Обращение на «ты». Примеры: «Пруф вместо скриншота», «Ключ только читает. Точка.», «Все постят рост. Никто не может это доказать.». Метки на русском («Подтверждено», «Продаётся»); английские только устоявшиеся термины (MRR, ARR, API, read-only).

## 9. Что НЕ копировать
Берклей-моно и Tiempos (платные), все цифры и проекты в каталоге — демо-данные, поэтому на экранах с примером всегда ставить плашку «Демо-данные».
